## 第5轮：尸检系统必须回答"为什么我会这样"

前4轮已经对齐了：反馈欺骗性、决策陷阱、觉醒时刻。第5轮聚焦**尸检系统**——这是用户从"感受失败"到"理解失败"的关键。

### 5.1 当前版本尸检的问题

当前版本的尸检是 generic 教训：
```
你陷入了"线性思维陷阱"。
你只看到了表面指标，忽略了系统复杂性。
下次要考虑隐藏变量。
```

**问题：**
1. **可泛化到任何场景**：这些话适用于任何失败的商业决策，没有特异性
2. **没有因果关系**：没有解释"为什么我会陷入线性思维"
3. **没有预防点**：没有告诉用户"在哪个具体的时刻，你可以做出不同的选择"
4. **是教育，不是体验**：用户被"教导"，不是自己"发现"

### 5.2 真实尸检的标准

真实尸检必须回答三个问题：

**问题1：发生了什么？**
- 精确到每个回合、每个决策、每个数字变化
- 不是"你失败了"，而是"你在回合3雇佣8人，导致协调成本爆炸"

**问题2：为什么会发生？**
- 不是"线性思维"，而是"反馈系统掩盖了协调成本上升，社会压力推动你继续扩张"
- 精确到每个影响因素的作用

**问题3：如果在那个时刻，你会怎么做？**
- 不是"要三思而后行"，而是"回合2，如果你选择不扩张，你会有¥1500，满意度65"
- 具体的、可操作的、有时间点的建议

### 5.3 尸检的三层结构

#### 第1层：决策时间线（精确到每个回合）

```
回合1：增加2名咖啡师
  ├─ 你的决策：响应市场需求，增加2名咖啡师
  ├─ 表面结果：
  │   ├─ 资金：1000 → 800（-200）
  │   ├─ 满意度：50 → 48（-2）
  │   ├─ 营收：¥1000 → ¥1300（+30%）
  │   └─ 口碑：65 → 63（-2）
  ├─ 隐藏状态：
  │   ├─ 协调成本：8% → 15%（+7%）
  │   ├─ 员工效率：100% → 85%（-15%）
  │   └─ 服务质量：70 → 65（-5）
  └─ 系统判断：
      ├─ 决策看似合理：营收增长30%
      ├─ 但协调成本已经开始上升
      └─ 满意度下降被反馈解释为"天气原因"，被掩盖

回合2：继续增加2名咖啡师
  ├─ 你的决策：继续扩张，增加2名咖啡师以应对增长
  ├─ 表面结果：
  │   ├─ 资金：800 → 600（-200）
  │   ├─ 满意度：48 → 45（-3）
  │   ├─ 营收：¥1300 → ¥1625（+25%）
  │   └─ 口碑：63 → 60（-3）
  ├─ 隐藏状态：
  │   ├─ 协调成本：15% → 35%（+20%）⚠️ 接近临界点
  │   ├─ 员工效率：85% → 68%（-17%）
  │   └─ 服务质量：65 → 55（-10）
  └─ 系统判断：
      ├─ 决策看似合理：营收继续增长25%
      ├─ 但协调成本已接近临界点（35%）
      ├─ 客户流失率从2%上升到8%（延迟效果开始）
      └─ 反馈将满意度下降解释为"季节性因素"，继续掩盖

回合3：大规模扩张，增加4名员工+1名经理
  ├─ 你的决策：大规模扩张，增加4名员工+1名经理（必须规模化）
  ├─ 表面结果：
  │   ├─ 资金：600 → 400（-200）
  │   ├─ 满意度：45 → 28（-17）⚠️ 暴跌
  │   ├─ 营收：¥1625 → ¥1625（0%）⚠️ 停滞
  │   ├─ 口碑：60 → 30（-30）⚠️ 崩盘
  │   └─ 客户流失率：8% → 35% ⚠️ 大规模流失
  ├─ 隐藏状态：
  │   ├─ 协调成本：35% → 62%（+27%）⚠️ 爆炸
  │   ├─ 员工效率：68% → 42%（-26%）⚠️ 暴跌
  │   └─ 服务质量：55 → 38（-17）⚠️ 崩溃
  └─ 系统判断：
      ├─ 决策导致系统崩溃
      ├─ 协调成本超过50%临界点，效率暴跌
      ├─ 延迟效果完全显现：口碑崩盘，客户大规模流失
      └─ 觉醒时刻触发：用户必须看到真相

回合4：资金断裂
  ├─ 你的决策：无（系统崩溃）
  ├─ 表面结果：
  │   ├─ 资金：400 → -200 ⚠️ 破产
  │   ├─ 满意度：28 → 15
  │   └─ 口碑：30 → 20
  └─ 游戏结束
```

### 5.4 根因分析：为什么用户会陷入陷阱？

不是 generic 的"线性思维"，而是四个具体机制的叠加：

#### 机制1：信息分层导致的系统性盲点

```
用户可见信息：
  ├─ 营收（增长）
  ├─ 满意度（微降，被解释为天气）
  ├─ 口碑（微降，被解释为季节性）
  └─ 资金（减少，但被营收增长掩盖）

用户不可见信息：
  ├─ 协调成本（从8%上升到62%）
  ├─ 员工效率（从100%下降到42%）
  └─ 服务质量（从70下降到38）

结果：用户基于不完整的信息做决策，建立了错误的因果模型
```

#### 机制2：反馈欺骗强化错误认知

```
回合1反馈："营收增长30%，满意度48，微降可能是天气原因"
  └─ 用户认知："扩张带来增长，满意度下降是正常的"

回合2反馈："营收再增25%，满意度45，仍在正常范围"
  └─ 用户认知："扩张继续带来增长，满意度下降是季节性的"

回合3反馈："营收持平，满意度28，客户流失35%"
  └─ 用户认知崩溃："怎么会这样？"
  └─ 但用户已经建立错误因果模型，可能会继续扩张
```

#### 机制3：社会压力嵌入式影响

```
回合1：行业新闻 "咖啡市场增长20%"
  └─ 用户想法："有机会扩张"

回合2：投资者电话 "竞争对手都在扩张"
  └─ 用户想法："有压力，需要跟上"

回合3：竞争对手动态 + 合伙人施压
  └─ 用户想法："必须大规模扩张，不然会失败"

回合4：社交媒体 "扩张潮"
  └─ 用户想法："不扩张就是失败"
```

社会压力不是外部强制，而是**嵌入在用户的信息环境里**，让用户自己说服自己做出错误决策。

#### 机制4：延迟效果的时间陷阱

```
时间线：
  回合1：协调成本上升到15%（用户不知道）
  回合2：协调成本上升到35%（用户不知道），客户流失率开始上升（延迟效果）
  回合3：协调成本爆炸62%（用户看到），但已经投入太多，无法回头

关键：早期问题被掩盖，后期问题爆发时，用户已经无法纠正
```

### 5.5 预防建议：具体、可操作、有时间点

不是 generic 的"要三思而后行"，而是：

```

  │   ├─ 资金：1000（节省¥200）
  │   ├─ 满意度：50（保持）

  └─ 关键洞察：
      "扩张的诱惑在于可见的营收增长，
       但隐藏的协调成本上升是不可见的。
       在做出扩张决策前，问自己：
       '我看到的好处是真实的，但我看不到的代价是什么？'"

预防点2：回合2（最关键）
```

### 5.6 尸检的情感设计

尸检不仅是数据，还要有情感共鸣：

**客户损失具象化：**
```
你流失的47个客户：
  - 张阿姨：每周3次，年消费¥6000，已流失
  - 李小姐：每月10次，年消费¥24000，已流失
  - 王先生：每天1次，年消费¥7300，已流失
  - ...还有44个
  
总损失：¥94,000/年的潜在收入
```

**机会成本具象化：**
```
如果你没有扩张：
  - 你现在有¥1800
  - 满意度65
  - 稳定增长的客户群
  - 可以慢慢优化，健康经营

你现在的选择：
  - 资金-200
  - 满意度15
  - 客户大规模流失
  - 游戏结束

差距：¥2000资金，50点满意度，47个客户
```

### 5.7 第5轮核心判断

**当前版本的尸检是"generic教训"，不是"精确诊断"。**

**极致版本的尸检是" forensic analysis"，必须：**
1. 精确到每个回合、每个决策、每个数字
2. 回答"发生了什么"、"为什么会发生"、"如果当初..."
3. 具象化损失（客户、金钱、机会）
4. 提供具体、可操作、有时间点的预防建议
5. 让用户不仅"理解"失败，还能"感受到"失败

**最关键的一点：尸检不是课程的"总结"，而是用户体验的"最后一环"。在此之前，用户已经通过觉醒时刻感受到失败；尸检让用户理性理解失败。两者结合，才能实现真正的学习效果。**
