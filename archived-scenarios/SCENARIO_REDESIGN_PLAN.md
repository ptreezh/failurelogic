# 认知陷阱平台深度重构计划

## 总目标
将 13 个场景从"浅层选选项看结果"升级为"具有非线性失败逻辑、实时认知训练、深度交互界面"的认知偏差训练系统。

## 核心问题诊断

### 1. 失败逻辑缺乏深度
- **现状**：每个回合 = 选选项 -> 看反馈 -> 下一回合。所有路径收敛到相同结果。
- **问题**：没有分支、没有级联、没有真正的非线性后果。用户无法体验"一步错，步步错"的失败逻辑。
- **改进**：每个决策应触发：
  - 即时反馈（直接后果）
  - 延迟反馈（1-3 回合后显现）
  - 级联反馈（触发后续事件的连锁反应）
  - 阈值反馈（累积到临界点后突然崩溃）

### 2. 认知训练目标模糊
- **现状**：只有投资场景有简单的确认偏误分析，其他场景没有明确的认知偏差检测。
- **问题**：用户不知道自己正在训练什么认知偏差，也没有觉醒时刻。
- **改进**：
  - 每个场景明确 2-3 个核心认知偏差
  - 实时检测并提示偏差
  - 觉醒时刻：特定回合设计为"aha moment"
  - 决策模式追踪：线性思维、锚定效应、可得性启发等

### 3. 交互界面停留在表层
- **现状**：Turn page = 静态选项列表。没有动态元素。
- **问题**：用户感觉像是在做问卷，而不是在体验复杂的决策过程。
- **改进**：
  - 动态指标可视化（实时更新的图表、进度条、热力图）
  - 情景化叙事（根据用户选择动态变化的故事线）
  - 多阶段反馈（即时 -> 短期 -> 长期）
  - 决策路径追踪（可视化用户的决策树）

## 场景重构矩阵

### 1. 咖啡店经营挑战
- **认知目标**：线性思维陷阱、边际效应递减、协同成本
- **失败逻辑**：
  - 雇佣过多员工 -> 协调成本指数增长 -> 服务质量下降 -> 客户流失
  - 过度营销 -> 短期客流激增 -> 服务跟不上 -> 口碑崩盘
  - 忽视时间延迟 -> 今天投入明天就想见效 -> 决策急躁
- **觉醒时刻**：第 3 回合，用户发现投入翻倍但收益没有翻倍
- **交互增强**：
  - 实时客流/满意度曲线图
  - 员工协调成本热力图
  - 决策延迟反馈提示器

### 2. 恋爱关系时间延迟
- **认知目标**：时间延迟偏差、即时满足偏好、过度投入陷阱
- **失败逻辑**：
  - 过度沟通 -> 对方感到窒息 -> 关系质量反而下降
  - 期望即时反馈 -> 每次投入后马上期待回报 -> 失望累积
  - 忽视非语言信号 -> 只关注自己做了什么，不看对方真正需要什么
- **觉醒时刻**：第 4 回合，用户发现自己的"关心"被对方误解为"控制"
- **交互增强**：
  - 关系温度计（实时显示关系质量）
  - 投入-回报时间线（可视化延迟效应）
  - 对方情绪状态指示器

### 3. 投资决策挑战
- **认知目标**：确认偏误、信息处理偏向、分析瘫痪
- **失败逻辑**：
  - 只搜索支持自己观点的信息 -> 忽视风险信号 -> 投资失误
  - 过度研究 -> 错过最佳投资时机
  - 锚定效应 -> 过度依赖初始信息
- **觉醒时刻**：第 4 回合，用户发现自己的信息选择存在明显偏见
- **交互增强**：
  - 信息源偏见分析仪
  - 研究时间 vs 机会成本对比图
  - 决策自信度 vs 实际准确率对比

### 4. 扩展多阶段决策
- **认知目标**：决策疲劳、 sunk cost fallacy、阶段性目标失衡
- **失败逻辑**：
  - 前期成功 -> 过度自信 -> 后期冒险决策
  - 沉没成本 -> 不愿放弃失败项目
  - 阶段目标冲突 -> 短期目标损害长期利益
- **觉醒时刻**：第 6 回合，用户发现前期成功导致了后期盲目自信
- **交互增强**：
  - 阶段目标雷达图
  - 决策疲劳度指示器
  - 沉没成本追踪器

### 5. 气候变化政策
- **认知目标**：复杂系统思维、时间偏好偏差、公平原则偏见
- **失败逻辑**：
  - 只看短期政治收益 -> 忽视长期气候风险
  - 统一标准 -> 忽视各国差异 -> 协议破裂
  - 技术乐观主义 -> 过度依赖技术创新
- **觉醒时刻**：第 3 回合，气候风险突然爆发
- **交互增强**：
  - 全球温度曲线预测
  - 国家满意度地图
  - 延迟效应时间线

### 6. 金融危机应对
- **认知目标**：系统性思维、风险传染、监管俘获
- **失败逻辑**：
  - 救市 -> 道德风险 -> 下次更大危机
  - 不救市 -> 系统性崩溃
  - 过度自信 -> 风险模型失效
- **觉醒时刻**：第 4 回合，发现自己的干预造成了更大的风险
- **交互增强**：
  - 系统性风险网络图
  - 市场信心指数
  - 决策延迟反馈环

### 7. AI 治理
- **认知目标**：创新-安全平衡、技术乐观主义、监管滞后
- **失败逻辑**：
  - 过度监管 -> 抑制创新 -> 落后于竞争对手
  - 放任自流 -> 安全事故 -> 公众恐慌
  - 技术中性幻想 -> 忽视 AI 的社会影响
- **觉醒时刻**：第 3 回合，AI 安全事故突然爆发
- **交互增强**：
  - AI 能力发展曲线
  - 创新-安全平衡仪表盘
  - 利益相关者压力图

### 8. 商业战略
- **认知目标**：竞争动态、市场定位、产品生命周期
- **失败逻辑**：
  - 盲目跟风 -> 同质化竞争 -> 价格战
  - 过度创新 -> 成本失控 -> 资金链断裂
  - 忽视竞争对手 -> 被颠覆
- **觉醒时刻**：第 2 回合，竞争对手推出颠覆性产品
- **交互增强**：
  - 市场份额动态图
  - 竞争压力热力图
  - 产品生命周期曲线

### 9. 公共政策
- **认知目标**： stakeholder 博弈、政策延迟、意外后果
- **失败逻辑**：
  - 平衡各方 -> 政策无效 -> 所有人都不满意
  - 强力推行 -> 强烈反弹 -> 社会动荡
  - 忽视 unintended consequences -> 解决了一个问题，创造了更大的问题
- **觉醒时刻**：第 2 回合，政策产生意外负面后果
- **交互增强**：
  -  stakeholder 满意度雷达图
  - 政策效果时间线
  - 意外后果追踪器

### 10. 个人理财
- **认知目标**：复利思维、即时满足、风险厌恶
- **失败逻辑**：
  - 过度储蓄 -> 错过投资机会 -> 实际购买力下降
  - 过度消费 -> 债务累积 -> 财务危机
  - 追逐高收益 -> 高风险 -> 本金损失
- **觉醒时刻**：第 3 回合，发现自己的"安全"策略实际上在亏损
- **交互增强**：
  - 资产增长曲线（复利 vs 线性）
  - 风险-收益散点图
  - 财务健康度评分

### 11. 社交媒体回声室
- **认知目标**：确认偏误、算法放大、群体极化
- **失败逻辑**：
  - 只关注认同观点 -> 认知窄化 -> 无法理解对立观点
  - 情绪化表达 -> 吸引同类 -> 排斥异己
  - 追求点赞 -> 内容极端化 -> 脱离现实
- **觉醒时刻**：第 3 回合，发现自己被困在信息茧房中
- **交互增强**：
  - 观点光谱图（显示用户观点的极化程度）
  - 信息茧房可视化
  - 社交网络影响力图

### 12. 历史案例
- **认知目标**：后见之明偏误、结果偏误、情境理解
- **失败逻辑**：
  - 事后诸葛亮 -> 以为自己不会犯同样的错误
  - 忽视情境压力 -> 简单归因
  - 结果偏误 -> 只看结果不看决策过程
- **觉醒时刻**：第 2 回合，发现自己的选择与历史决策惊人相似
- **交互增强**：
  - 决策对比图（用户 vs 历史决策者）
  - 情境压力指数
  - 结果偏误检测器

### 13. 恋爱关系（Router）
- **认知目标**：情感推理、投射效应、关系脚本
- **失败逻辑**：
  - 以己度人 -> 把自己的需求强加给对方
  - 理想化 -> 忽视真实问题
  - 关系脚本 -> 按预设模式行事 -> 忽视真实互动
- **觉醒时刻**：第 3 回合，发现自己的"关心"实际上是在满足自己的需求
- **交互增强**：
  - 关系动态图
  - 情感表达匹配度
  - 投射效应检测器

## 技术架构

### 新核心类：CognitiveTrainer
```javascript
class CognitiveTrainer {
  // 检测当前决策中的认知偏差
  detectBiases(scenarioId, decision, history, state)
  
  // 生成实时认知反馈
  generateRealtimeFeedback(scenarioId, bias, decision, state)
  
  // 检测觉醒时刻
  checkAwakeningMoment(scenarioId, turn, history, state)
  
  // 分析决策模式
  analyzeDecisionPatterns(history)
  
  // 生成最终认知报告
  generateCognitiveReport(scenarioId, history, state)
}
```

### 新核心类：ScenarioNarrativeEngine
```javascript
class ScenarioNarrativeEngine {
  // 根据用户选择生成动态叙事
  generateNarrative(scenarioId, turn, decisions, history)
  
  // 生成分支后果
  generateConsequences(scenarioId, decision, state)
  
  // 生成延迟事件
  generateDelayedEvents(scenarioId, turn, decisions)
  
  // 检查游戏结束条件
  checkGameOver(scenarioId, state, history)
}
```

### 新核心类：MetricVisualizer
```javascript
class MetricVisualizer {
  // 生成实时指标 HTML
  renderLiveMetrics(scenarioId, state, history)
  
  // 生成决策路径图
  renderDecisionTree(history)
  
  // 生成偏差趋势图
  renderBiasTrend(history)
}
```

## 完成标准
1. 每个场景至少 3 个核心认知偏差被明确检测和反馈
2. 每个场景至少有 1 个觉醒时刻
3. 每个场景的失败逻辑具有非线性、级联、延迟特性
4. 每个场景的交互界面具有实时指标、动态反馈、决策追踪
5. 所有场景通过 JS 语法检查
6. 浏览器冒烟测试通过
7. 成功部署到线上
