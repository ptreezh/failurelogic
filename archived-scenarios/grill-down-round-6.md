## 第6轮：用户心理历程的精确设计

前5轮已经分别对齐了：反馈欺骗性、决策陷阱、觉醒时刻、尸检系统。第6轮聚焦**整体用户心理历程**——把前5轮的组件整合成一个连贯的、有情感弧线的体验。

### 6.1 当前版本的用户历程

当前版本的流程：
1. 开始游戏 → 看到场景介绍
2. 回合1：选择选项 → 看到反馈
3. 回合2：选择选项 → 看到反馈
4. 回合3：选择选项 → 看到觉醒文本
5. 回合4：选择选项 → 游戏结束
6. 看到尸检 → 结束

**问题：**
- 没有情感弧线
- 每一轮是独立的，没有累积效应
- 觉醒是突兀的，不是渐进的
- 没有"悬念→紧张→崩溃→反思"的叙事结构

### 6.2 真实陷阱的心理历程

真实陷阱的心理历程有五个阶段：

**阶段1：建立期望（回合1-2）**
- 用户看到机会
- 用户做出第一个决策
- 反馈强化用户的乐观预期
- 用户建立因果模型："扩张→增长"

**阶段2：压力累积（回合2-3）**
- 社会压力开始显现
- 用户感到有压力要跟上
- 反馈继续掩盖问题
- 用户继续扩张

**阶段3：预警信号（回合3早期）**
- 表面数据开始出现负面信号
- 但反馈提供合理归因
- 用户忽视或合理化这些信号

**阶段4：系统崩溃（回合3晚期-4）**
- 延迟效果完全显现
- 用户震惊
- 觉醒时刻触发
- 用户感受到失败的严重性

**阶段5：反思学习（游戏结束后）**
- 尸检系统展示精确的因果链
- 用户理解失败原因
- 用户学习到认知偏差

### 6.3 五阶段心理历程的精确设计

#### 阶段1：建立期望（回合1）

**用户进入时的心理状态：**
- 好奇、谨慎
- 想"做好"这个决策
- 没有压力，没有紧迫感

**系统设计：**

**开局场景：**
```
你接手了一家小型咖啡店。
  位置：城市中心，周边有办公楼和学校
  团队：3名咖啡师
  资金：¥1000
  满意度：50
  口碑：65

行业背景：
  咖啡市场年增长20%，精品咖啡需求旺盛。
  周边正在开发新办公楼，预计增加2000名上班族。
  
你决定如何开始？
```

**回合1选项：**
```
A. 响应市场需求，增加2名咖啡师（投资¥200）
B. 维持现有团队，先观察市场反应
C. 减少员工，聚焦精品化路线（裁员1人，节省¥100）
```

- 选项A是"响应市场"，听起来最合理
- 选项B是"保守"，听起来错过机会
- 选项C是"收缩"，听起来消极
- 社会压力：行业新闻暗示"市场在增长，你应该扩张"

**回合1反馈（欺骗性）：**
```
你选择了A：响应市场需求，增加2名咖啡师。

市场反馈：
  - 营收增长30%，达到¥1300
  - 客户满意度48（微降，可能是天气原因）
  - 口碑63（略降，正常波动）
  
行业观察：
  - 咖啡市场年增长20%，你的增速超过市场
  - 周边办公楼正在开发，未来客流会增加
  - 竞争对手也在考虑扩张
  
你感觉：决策正确，市场在奖励你的扩张。
```

**用户心理状态：**
- "我做了正确的决策"
- "市场在增长，我抓住了机会"
- "满意度微降是正常的，可以接受"
- 建立了因果模型：扩张 → 增长

#### 阶段2：压力累积（回合2）

**用户进入回合2时的心理状态：**
- 自信
- 觉得"我知道怎么经营这家店"
- 没有意识到危险

**系统设计：**

**回合2触发事件（社会压力）：**
```
☕ 投资者来电
"我们注意到你的营收增长很好。
 竞争对手张老板刚开了分店，营收翻倍。
 你觉得什么时候扩张？
 我们要跟上市场，不然会落后。"

📰 行业新闻
"咖啡扩张潮：今年新增200家咖啡店，
 其中60%在市中心区域。
 市场窗口期有限，先发优势明显。"
```

**回合2选项：**
```
A. 继续扩张，增加2名咖啡师以应对增长（投资¥200）
B. 保持现有规模，优化现有团队效率
C. 甚至可以考虑减少员工，提高人均产出
```

- 选项A被社会压力强化为"理所当然"
- 选项B被暗示为"保守落后"
- 选项C被暗示为"不思进取"

**回合2反馈（欺骗性）：**
```
你选择了A：继续扩张，增加2名咖啡师。

市场反馈：
  - 营收再增25%，达到¥1625
  - 客户满意度45（仍在正常范围）
  - 老客户回头率92%（略降，可能是季节性因素）
  
行业观察：
  - 你的增速仍然超过市场平均
  - 但竞争对手张老板的分店开业了，营收翻倍
  - 投资者再次来电："很好，继续保持"
  
内部观察（微妙线索）：
  - 你注意到员工之间似乎有些忙乱
  - 新员工还在培训中，熟练度不够
  
你感觉：
  - "营收继续增长，决策正确"
  - "员工忙乱是暂时的，培训后会好"
  - "竞争对手在扩张，我不能停"
```

**用户心理状态：**
- "我在做正确的决策"
- "社会压力在推动我，但我自己也想扩张"
- "小问题（员工忙乱）是暂时的，会解决的"
- 没有意识到协调成本正在上升

#### 阶段3：预警信号（回合3早期）

**用户进入回合3时的心理状态：**
- 仍然自信
- 觉得"我掌握了经营规律"
- 但可能有一丝不安（满意度持续下降）

**系统设计：**

**回合3触发事件（压力升级）：**
```
💼 合伙人施压
"张老板的分店开业3个月，营收已经超过我们。
 我们要不要也开分店？
 或者至少大规模扩张，提升产能？"

📱 社交媒体
"咖啡扩张潮"成为热门话题。
 大家都在讨论谁抓住了机会，谁落后了。
 你的店被提及，但评论说"规模太小"。 
```

**回合3选项（沉没成本锁定）：**
```
A. 大规模扩张，增加4名员工+1名经理（必须规模化才能生存）
B. 维持现状，但营收增长已经停滞
C. 收缩，但已经投入太多，无法回头
```

- 选项A是"必须"的选择
- 选项B是"等死"
- 选项C是"承认失败"
- 沉没成本：已经投入¥400，如果收缩，前功尽弃

**回合3反馈（崩溃开始）：**
```
你选择了A：大规模扩张。

市场反馈（突然恶化）：
  - 营收：¥1625 → ¥1625（持平）⚠️ 停滞！
  - 客户满意度：45 → 28（-17）⚠️ 暴跌！
  - 客户流失率：8% → 35% ⚠️ 大规模流失！
  - 口碑：60 → 30（-30）⚠️ 崩盘！
  
内部观察：
  - 员工之间严重混乱
  - 服务质量明显下降
  - 老客户大面积流失
  
你感觉：
  - "怎么会这样？"
  - "是不是人还不够？"
  - "我需要更多人手来解决问题"
```

**用户心理状态：**
- 震惊
- 困惑
- 错误归因："人不够，需要更多人"
- 已经投入太多，无法回头

#### 阶段4：系统崩溃（回合3晚期-4）

**觉醒时刻触发：**

用户在回合3做出决策后，**强制**看到觉醒页面：

**第1层：数据冲击**
```
⚠️ 本回合客户流失报告

流失客户：47人
  - 张阿姨（老客户，每周3次）："等15分钟，咖啡做错了"
  - 李小姐（商务客户，每月10次）："环境嘈杂，不能带客户来了"
  - 王先生（学生，每天1次）："太吵了，去街角了"
  - ...还有44个

这47个客户：
  - 永远不会回来
  - 年消费总额：¥94,000
  - 连带影响：口碑崩盘，新客户增长率为-15%
```

**第2层：隐藏变量揭示**
```
隐藏的系统真相：

员工效率 vs 员工数量（倒U曲线）
  85% |     ● (3-4人，最佳规模)
      |    / \
      |   /   \
      |  /     \
  42% |/         ● (8人，你当前的位置)
      |___________________
        3   4   5   6   7   8

你现在在效率曲线的错误一侧。
```

**第3层：因果链**
```
雇佣8人 → 协调成本62% → 员工效率42% → 服务质量38
  → 客户失望 → 流失47人 → 口碑30 → 新客户-15%
```

**第4层：对比冲击**
```
如果保持3人：
  - 资金：¥1800
  - 满意度：65
  - 客户流失率：2%
  - 口碑：65
  - 年收入：¥156,000

你现在的选择：
  - 资金：¥400
  - 满意度：28
  - 客户流失率：35%
  - 口碑：30
  - 年收入：亏损

你多雇佣的5个人，每年花费¥60,000，
但导致客户流失价值¥94,000/年。

你赚了还是亏了？
```

**用户心理状态：**
- 震惊
- 恍然大悟
- "哦，我明白了..."
- "我被反馈欺骗了"
- "我被社会压力推着走"

**游戏结束：**
- 资金断裂，游戏结束
- 用户看到"游戏结束"页面
- 只有"复盘"按钮，没有"重新开始"

### 6.5 第6轮核心判断

**当前版本的用户历程是线性的、没有情感弧线的。**

**极致版本的用户历程是叙事性的、有情感弧线的：期望→压力→预警→崩溃→反思。**

**关键设计原则：**
1. 每一轮都累积前一轮的效果
2. 社会压力逐步升级，不是一次性
3. 反馈逐步掩盖问题，不是一次性
4. 觉醒是突兀的、不可回避的
5. 尸检是完整的、精确的、可操作的

**用户的心理历程必须是：**
1. "我在做正确的决策"（期望）
2. "社会在推动我，但我自己也想扩张"（压力）
3. "有点不对劲，但可能是暂时的"（预警）
4. "怎么会这样？"（崩溃）
5. "哦，我明白了..."（觉醒）
6. "我为什么会陷入这个陷阱？"（反思）

**只有完成这个完整的心理历程，用户才能真正理解失败的原因。**
